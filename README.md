# 📋 Bloco de Tarefas API

Uma aplicação simples de gerenciamento de tarefas desenvolvida com **Python e FastAPI**, com uma interface frontend em **HTML, CSS e JavaScript**.

O projeto foi criado com o objetivo de praticar o desenvolvimento de **APIs REST**, criação de endpoints, validação de dados e integração entre backend e frontend.

## 🚀 Tecnologias utilizadas

- 🐍 Python
- ⚡ FastAPI
- 📦 Pydantic
- 🌐 HTML5
- 🎨 CSS3
- ⚙️ JavaScript
- 🔥 Uvicorn

## 📌 Funcionalidades

- ✅ Listar tarefas
- ➕ Criar novas tarefas
- 🗑️ Excluir tarefas
- 🔎 Validação do título da tarefa
- 🌐 Integração entre frontend e API REST
- 📄 Documentação automática da API através do FastAPI
